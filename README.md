# WorkoutApp - iOS Приложение для Тренировок

Приложение для отслеживания тренировок, созданное с использованием SwiftUI для iOS.

## Функциональность

### 🏋️ Основные возможности
- **Создание тренировок** - добавление упражнений и подходов
- **Отслеживание прогресса** - сохранение результатов тренировок
- **Статистика** - графики и аналитика тренировок
- **Быстрый старт** - готовые шаблоны тренировок
- **Таймер** - отслеживание времени отдыха между подходами

### 📱 Экраны приложения
1. **Главная** - обзор статистики и быстрый доступ к функциям
2. **Список тренировок** - просмотр всех сохраненных тренировок
3. **Создание тренировки** - добавление новых тренировок и упражнений
4. **Детали тренировки** - подробная информация о конкретной тренировке
5. **Статистика** - графики прогресса и аналитика

### 🎯 Типы упражнений
- **Повторы** - классические упражнения с количеством повторений
- **Время** - упражнения на время (планка, бег и т.д.)
- **Вес** - отслеживание весов и прогресса

## Технические детали

## Установка и запуск

### Требования
- Xcode 15.0+
- iOS 17.0+
- Swift 5.9+

### Запуск
1. Откройте `WorkoutApp.xcodeproj` в Xcode
2. Выберите симулятор или устройство
3. Нажмите ⌘+R для запуска

## Использование

### Создание первой тренировки
1. Откройте вкладку "Создать"
2. Введите название тренировки
3. Добавьте упражнения
4. Для каждого упражнения добавьте подходы
5. Сохраните тренировку

### Быстрый старт
1. На главной странице нажмите "Начать тренировку"
2. Выберите готовый шаблон или создайте свою
3. Начните тренировку

### Просмотр статистики
1. Перейдите на вкладку "Статистика"
2. Выберите период (неделя/месяц/год)
3. Изучите графики и аналитику
