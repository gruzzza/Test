# FitTracker - Продвинутое iOS Приложение для Тренировок

Современное iOS приложение для отслеживания тренировок с расширенными возможностями, созданное с использованием SwiftUI и современных архитектурных паттернов.

## 🚀 Основные возможности

### 📱 **Современный интерфейс**
- **SwiftUI** - нативный UI фреймворк Apple
- **Адаптивный дизайн** - поддержка iPhone и iPad
- **Темная тема** - автоматическая поддержка системных настроек
- **Анимации** - плавные переходы и интерактивность
- **Кастомные компоненты** - переиспользуемые UI элементы

### 🏋️ **Управление тренировками**
- **Создание тренировок** - детальная настройка упражнений и подходов
- **Шаблоны тренировок** - готовые планы для разных целей
- **Таймер тренировок** - отслеживание времени работы и отдыха
- **Прогресс-трекинг** - отслеживание выполнения упражнений
- **Категории тренировок** - силовые, кардио, йога, кроссфит и др.

### 📊 **Аналитика и статистика**
- **Детальная статистика** - графики и диаграммы прогресса
- **Анализ по периодам** - неделя, месяц, год
- **Топ упражнений** - самые популярные упражнения
- **Прогресс по весам** - отслеживание увеличения нагрузок
- **Сожженные калории** - подсчет энергозатрат

### 🏆 **Система достижений**
- **Мотивационные достижения** - награды за прогресс
- **Категории достижений** - тренировки, упражнения, время, вес
- **Прогресс-бар** - визуализация приближения к цели
- **Уведомления** - оповещения о новых достижениях

### 👤 **Профиль пользователя**
- **Персональные данные** - возраст, вес, рост, цели
- **Уровень подготовки** - начинающий, средний, продвинутый
- **BMI калькулятор** - автоматический расчет индекса массы тела
- **Цели фитнеса** - похудение, набор массы, сила, выносливость

### 🔄 **Планы тренировок**
- **Готовые программы** - структурированные планы тренировок
- **Длительность планов** - от 4 до 12 недель
- **Адаптация под уровень** - планы для разных уровней подготовки
- **Прогресс выполнения** - отслеживание выполнения плана

### ⏱️ **Таймер и уведомления**
- **Таймер отдыха** - автоматический отсчет времени между подходами
- **Уведомления** - напоминания о тренировках
- **Звуковые сигналы** - оповещения о смене упражнений
- **Фоновый режим** - работа таймера при свернутом приложении

### 🏥 **Интеграция с Apple Health**
- **Синхронизация данных** - автоматическая передача в HealthKit
- **Пульс** - отслеживание сердечного ритма
- **Калории** - синхронизация сожженных калорий
- **Активность** - интеграция с Apple Watch

## 🛠 Техническая архитектура

### **Архитектурные паттерны**
- **MVVM** - Model-View-ViewModel для разделения логики
- **Combine** - реактивное программирование
- **ObservableObject** - управление состоянием
- **Dependency Injection** - внедрение зависимостей

### **Структура проекта**
```
FitTracker/
├── Models.swift              # Модели данных
├── ViewModels.swift          # ViewModels для управления состоянием
├── Services.swift            # Сервисы для работы с данными
├── Views.swift               # SwiftUI представления
├── Extensions.swift          # Расширения для удобства
├── FitTrackerApp.swift       # Точка входа приложения
└── ContentView.swift         # Главный экран
```

### **Модели данных**
- **Workout** - тренировка с упражнениями и метаданными
- **Exercise** - упражнение с подходами и параметрами
- **ExerciseSet** - подход с повторениями, весом, временем
- **WorkoutPlan** - план тренировок на определенный период
- **Achievement** - достижение с прогрессом и условиями
- **UserProfile** - профиль пользователя с целями

### **Сервисы**
- **DataService** - локальное хранение данных
- **HealthService** - интеграция с Apple Health
- **NotificationService** - управление уведомлениями
- **AnalyticsService** - аналитика и метрики
- **WorkoutTemplateService** - шаблоны тренировок

## 🔧 Установка и запуск

### **Требования**
- Xcode 15.0+
- iOS 17.0+
- Swift 5.9+
- macOS 14.0+

### **Запуск**
1. Откройте `FitTracker.xcodeproj` в Xcode
2. Выберите симулятор или устройство
3. Нажмите ⌘+R для запуска

### **Настройка**
1. Настройте Bundle Identifier
2. Добавьте иконки приложения
3. Настройте разрешения для HealthKit
4. Настройте уведомления
